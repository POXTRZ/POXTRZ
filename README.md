Collaborative Android marketplace application developed with **Kotlin and Firebase**.

My contributions included Firebase integration, authentication, application functionality, debugging, testing and UI improvements.

**Stack:** `Kotlin` · `Firebase Authentication` · `Cloud Firestore` · `Android Studio`
